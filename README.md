# Disaster Tweet Classifier

A simple NLP and Machine Learning project that classifies a tweet as **Disaster-related** or **Non-disaster** using TF-IDF and Logistic Regression.

## Features

- Loads and checks the tweet dataset.
- Converts tweet text into TF-IDF features.
- Trains a Logistic Regression classifier.
- Reports accuracy, precision, recall, and F1-score.
- Saves a confusion matrix.
- Provides a Flask website for classifying new tweets.

## Requirements

- Python 3
- The dataset file `tweets.csv`

## Setup

Open a terminal in the project folder.

Create a virtual environment if you have not already created one:

```bash
python -m venv venv
```

Activate it in Windows PowerShell:

```powershell
.\venv\Scripts\Activate.ps1
```

Install the required libraries:

```bash
python -m pip install -r requirements.txt
```

## Check the Dataset

Make sure `tweets.csv` is in the project folder, then run:

```bash
python check_dataset.py
```

The dataset used during development contained 7,613 rows and these columns: `id`, `keyword`, `location`, `text`, and `target`. The model uses `text` as input and `target` as the label.

## Train the Model

Run:

```bash
python train_model.py
```

This trains the TF-IDF and Logistic Regression pipeline components and generates:

- `disaster_model.pkl`
- `tfidf_vectorizer.pkl`
- `confusion_matrix.png`

The recorded test accuracy during development was **81.42%**. Your results may vary if the dataset, code, or library versions change.

## Run the Website

After training has generated the two `.pkl` files, run:

```bash
python app.py
```

Open this address in your browser:

```text
http://127.0.0.1:5000
```

Enter a tweet and click **Classify Tweet**. The website displays the model's predicted category.

## Example Tweets

```text

```

Non-disaster example:


Predictions are generated by the trained model and may sometimes be incorrect. This project is a learning prototype, not an official emergency alert system.

## Limitations

- The model is trained on a particular labelled tweet dataset.
- It may misclassify sarcasm, metaphorical language, slang, or unfamiliar events.
- The application does not monitor social media in real time.
- Predictions should not be used as the sole basis for emergency decisions.
